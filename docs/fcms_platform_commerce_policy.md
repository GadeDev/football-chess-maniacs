# FootballChessManiacS 課金方針

決定日: 2026-09-09 / Owner: 栁堀貴之

## 現行仕様

- 課金・決済はUniverso Fútbol Platformで行う。FCMSに独自の決済機能を持たせない。
- INGOTは不要。ゲーム内通貨、通貨パック、残高表示、チャージ、コマ価格への通貨換算、通貨消費による購入を仕様から削除する。
- FCMSはPlatformの商品への導線と、Platformが管理する購入権利のゲーム内反映を担当する。
- 販売商品、価格、販売開始時期は別途決める。この方針だけで商品登録や課金開始を許可したことにはならない。
- 返金・取消による権利の扱いもPlatformの契約に合わせる。具体的なAPI・metadataの契約は接続時に確認する。

## 旧仕様の扱い

旧INGOTサービス手順書は削除した。旧通貨パック作成、残高移行、通貨専売商品の再公開を再開作業に含めない。過去の実装・監査記録は当時の証跡であり、現行仕様として実行しない。

## 実装との差分（未対応）

今回の変更は仕様文書のみ。`src/api/shop.ts`の旧wallet/ingots/ingot-products/purchase経路、`src/types/piece.ts`の換算関数、旧通貨Webhook処理、関連テスト・翻訳・DB定義等の残存は、コード削除完了を意味しない。

実装整理時は呼出元を照合し、Platformへの商品導線・権利同期を維持したうえで不要な通貨処理を除去する。既存DB・migration履歴・Platform台帳の削除や変更は今回行わない。

ゲーム全体の再開範囲、コード変更、配備、販売開始は引き続き未承認。
